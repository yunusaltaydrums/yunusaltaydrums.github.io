# ALTAY Ritim Atölyesi

Yunus Altay'ın Seviye 1 ritim varyasyonları uygulaması. Tek dosya HTML, telefona "Ana Ekrana Ekle" ile kurulur (PWA).

- `index.html` — uygulamanın tamamı (notalar, sesler, açılış kodu kontrolü)
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — ana ekran simgesi ve tam ekran açılış
- `sw.js` — çevrimdışı çalışma

Yayın: GitHub Pages (main dalı, kök klasör). Açılış kodları Kod Üretici sayfasından verilir.
